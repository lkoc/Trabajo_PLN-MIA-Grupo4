# Archivo histórico

Este directorio conserva evidencia anterior a la reorganización v2. Los archivos no son dependencias del flujo activo.

- `estructura_anterior/`: README y cuadernos originales, incluidos sus resultados incrustados.
- `contrato_4_danos_seguro_derivado/`: etiquetado por API e informes del contrato de cuatro daños con `SEGURO` derivado.
- `taxonomia_v1_3/`: paquete exacto que recibió el etiquetador histórico.
- `lm_studio/`: implementación e informes de LM Studio retirados del flujo activo.
- `implementacion_anterior/`: scripts originales.
- `material_curso/`: clases y recursos docentes.
- `flujo_reorganizado_v2/`: orquestadores v2 reemplazados después de simplificar el flujo activo.
- `03_2_etiquetado_llm_api/`: estado local retirado del antiguo etiquetado por API; cualquier `.env` permanece ignorado y no forma parte del flujo actual.
- `05_frontend_despliegue/`: bundle autocontenido generado por el frontend anterior; sus artefactos grandes permanecen ignorados por Git.

Todos los cuadernos vigentes se encuentran bajo `flujo/`. Ninguna carpeta de
primer nivel fuera de `flujo/` debe interpretarse como una etapa ejecutable
actual por conservar numeración histórica.

El inventario [`Planning/inventario_pre_reorganizacion.json`](../Planning/inventario_pre_reorganizacion.json) registra tamaño y SHA-256 de 2.168 archivos previos. Una discrepancia documental no autoriza a reescribir los artefactos históricos: se corrige mediante una nueva versión y un enlace de reemplazo.
