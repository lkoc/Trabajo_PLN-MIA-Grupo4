# Figuras del paper

Esta carpeta contiene los diagramas usados o propuestos para el paper IEEE.

## Archivos

- `pipeline_moderacion.tex`: figura TikZ incluida directamente en el paper.
- `arquitectura_sistema.mmd`: version Mermaid del flujo.
- `arquitectura_sistema.md`: version documentada del diagrama Mermaid.

Las figuras deben explicar el flujo del artefacto y no reemplazar la descripcion metodologica.
