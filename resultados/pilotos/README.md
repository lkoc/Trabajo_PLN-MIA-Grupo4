# Pilotos locales

Los pilotos de Ollama se guardan aquí. Una muestra menor de 200 casos es un smoke test técnico y no selecciona el modelo semántico. Las referencias humanas históricas estuvieron asistidas y no constituyen gold standard ciego.

El intento del 5 de agosto de 2026 está documentado en `INFORME_PILOTO_OLLAMA_20260805.md`: la muestra quedó preparada, pero el proxy del entorno impidió completar la instalación de los tres modelos; por tanto no existe selección ni métricas semánticas.
