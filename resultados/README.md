# Resultados

Carpeta para metricas, figuras, logs y reportes del experimento.

## Subcarpetas

- `metricas/`: metricas por modelo y categoria.
- `figuras/`: matrices de confusion, graficos y visualizaciones.
- `logs/`: registros de ejecucion y decisiones metodologicas.

El paper debe citar solo resultados verificados y reproducibles.
