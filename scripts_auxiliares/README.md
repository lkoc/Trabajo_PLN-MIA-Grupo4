# Scripts auxiliares

Esta carpeta contiene utilidades de apoyo para diagramas, revision visual y compilacion. No contiene datos ni modelos.

## Uso esperado

- Generar o exportar diagramas de arquitectura.
- Revisar posibles problemas de desborde visual en presentaciones.
- Automatizar verificaciones locales del material entregable.

Los scripts deben mantenerse genericos y no deben incluir llaves, credenciales ni llamadas a APIs externas.
